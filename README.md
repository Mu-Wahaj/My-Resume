# My-Resume
Welcome to my resume repository! 

This is a simple, responsive resume I built from scratch using **HTML** and **CSS**. I created this to practice my front-end web development skills and to have a clean, professional version of my resume that I can share online.

## 📁 Repository Structure
- `resume.html` - The main HTML file containing the resume.
- `README.md` - This documentation file.

## ✨ Features Included
The resume contains the following required sections:
- **Name:** Muhammad Wahaj
- **Contact Information:** Email and City/Country
- **Work Experience:** PNY Trainings/Bootcamp
- **Education:** University of the Punjab
- **Projects:** 
  - Hospital Management System (C/C++)
  - Restaurant Website (React/JavaScript)
  - E-Commerce Website (React/JavaScript)
- **Skills, Tools & Technologies:** C++, JavaScript, React, HTML5, CSS3, Git, VS Code, and more.

## 🛠️ Technologies Used
- **HTML5:** For the structure and content of the resume.
- **CSS3:** For styling, layout, and responsive design.
- **FontAwesome:** For clean, professional icons (Email, LinkedIn, GitHub).

## 🚀 How to View
1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/Mu-Wahaj/webtech-assignment01.git
   ```
2. Navigate to the project folder.
3. Open `resume.html` in any web browser (Chrome, Firefox, Edge) to view the resume.
